# Camera Color Picker App

I one day randomly wanted to get the hex color code of something in real life, but I didn't wanted to take a screenshot and send to to my computer to take a loot at it.

So I actually begin to have the idea of using a color sensor and plug it to an arduino, but the color wasn't accurate (the sensor emitted too much light).
Therefor I changed it to an android app. (which is the first time that I make an android app)
